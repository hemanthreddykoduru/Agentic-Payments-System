# Settlements + Reports

SETTLEMENTS: overview card (Previous / Today's / Next settlement +
Available balance, holiday note), schedule strip (Domestic T+2 /
International T+7), table Created|Settlement ID(copy)|UTR(copy)|Net
amount|Status; detail drawer with breakup (gross, fee, tax, net) and
contained payments list; Settlement Preferences sub-page (T+0 locked
0.15% / T+1 locked 0.09% / T+2 selected — LockedTierCard pattern).
REPORTS: tabs Overview|Downloads|Schedules; Overview = grouped
CatalogCards (Settlements, Settlement Recon, Payments, Refunds, Orders,
QR, Links, Subscriptions) each with Download modal (AccordionStepModal:
report type → duration incl. FY shortcuts → email toggle); Custom
Report builder (base type, name, drag-drop column picker max 50,
rename) per PRD; Downloads table with Processing→Ready states (max 3
concurrent banner); Schedules table with edit. Downloads produce real
CSV files from DB. Acceptance: CSV opens; schedule persists.
