# Agent Console + NL Queries + Migration Wizard

AGENT CONSOLE: agents list (name, model, scopes, status), per-agent
activity timeline (action, tool, outcome, cost), permission editor,
"pause agent", audit export; Dunning agent card (auto-retry failed
subs at simulated optimal times) with approve/pause; Dispute agent:
drafts evidence from payment data (template-based NL generation,
editable, one-click submit).
NL QUERY BAR (Home + Reports): parse simple intents
("failed UPI payments last 7 days", "top 5 customers by volume") into
Prisma queries via a small intent-mapper (no external LLM needed);
render result table + chart.
MIGRATION WIZARD: choose source (Razorpay/Stripe), paste keys (stored
encrypted, mock-validate), preview imported customers/links, generate
code-diff snippets replacing old SDK calls with Agentic SDK, checklist
to go live.
Acceptance: NL bar returns correct seeded answers for 5 canned queries.
