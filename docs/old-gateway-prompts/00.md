# Bootstrap, Schema, Seed

Read CLAUDE.md and docs/PRD.md. Initialize the repo: Next.js 15 (App
Router, TS strict, src/), Tailwind, Prisma+SQLite, install framer-motion,
recharts, zustand, lucide-react, zod, qrcode.
1) Write prisma/schema.prisma implementing PRD §7 with enums
   (PaymentStatus created/authorized/captured/failed/refunded;
   OrderStatus created/attempted/paid; SettlementStatus
   created/processed/failed; Subscription states; Invoice states),
   indexes on merchant_id, and a LedgerEntry model for double-entry.
2) Migrate. 3) Write prisma/seed.ts creating: demo merchant
   "Acme Stores", 3 users (owner/admin/auditor), test+live ApiKeys
   (rzp-style: ap_test_…/ap_live_…), 2 webhooks, 40 customers,
   300 payments across 90 days (mixed methods UPI/card/netbanking,
   ~6% failed, few refunds/disputes), 12 settlements (T+2), 6 links,
   3 pages, 2 QR, 8 invoices, 2 plans, 4 subscriptions, 3 agents with
   20 agent_actions. Deterministic seed.
Acceptance: `npx prisma migrate dev` + `npx prisma db seed` +
`npm run build` all green; `npx prisma studio` shows data.
