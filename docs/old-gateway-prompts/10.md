# Sandbox PSP + Public API + Webhooks (the engine)

Build the simulated PSP + public API per PRD §8:
1) /v1 routes with Basic auth against ApiKey, tenant-scoped, zod
   validated, Idempotency-Key honored. Orders create → hosted checkout
   route /checkout/:orderId (glass UI, method tabs UPI/Card/Netbanking;
   UPI: success@agenticpay / failure@agenticpay; cards: 4111… success,
   4000…0002 declined; mock bank page with Success/Failure buttons).
2) State machine created→authorized→captured (auto-capture setting
   honored)→refunded; late-authorization simulator (rare).
3) Webhook dispatcher: signs HMAC-SHA256, retries exponential backoff,
   logs deliveries (visible in Developers→Webhooks logs), 2XX-in-5s rule.
4) Settlement simulator: cron-like job on simulated clock, T+2, creates
   Settlement + LedgerEntries (gross/fee/tax/net), updates balances
   (segregated Online/In-Person).
5) Refunds (normal/instant speed), disputes seed transitions.
Acceptance (the 90% loop): curl create order with test key → open
checkout → pay success@agenticpay → webhook 200 in logs → dashboard
shows captured → settlement appears after simulated T+2 → CSV report
includes it. Write scripts/e2e-sandbox.sh automating this.
