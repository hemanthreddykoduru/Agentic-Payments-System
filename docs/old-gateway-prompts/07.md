# Invoices, Subscriptions, Customers, Smart Collect

INVOICES: list with state pills (draft/issued/partially_paid/paid/
overdue/expired); builder with customer select-or-create modal, line
items (GST rate, HSN/SAC, tax inclusive/exclusive, CGST/SGST vs IGST
auto by place-of-supply), 2048-char notes/terms, partial payments
toggle; live PDF preview pane; actions Issue/Resend/Download/Cancel;
email mock.
SUBSCRIPTIONS: tabs Plans | Subscriptions; plan builder (interval,
trial, upfront); subscription list (Active/Paused/Cancelled/Halted)
with pause/resume/cancel + payment history + retry button.
CUSTOMERS: table + create/edit modal + profile drawer (payments,
invoices, subs, notes tabs).
SMART COLLECT: virtual account/UPI-ID list, create identifier,
payments-by-UTR view, close action.
Acceptance: issuing an invoice creates a pay link; paying it in
sandbox flips it to paid.
